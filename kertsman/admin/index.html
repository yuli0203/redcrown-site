ניהול הדירות

הזינו את סיסמת הניהול כדי להיכנס.

הסיסמה מגנה על המסך הזה מפני מבקרים מזדמנים בלבד. היא אינה מגנה על השרת, ולכן אין להשתמש בסיסמה שמשמשת אתכם במקום אחר.

שחזור גישה

אין צורך לזכור את הסיסמה הישנה. בוחרים כאן סיסמה חדשה, מקבלים שורה אחת להחלפה בקובץ, ומאותו רגע הסיסמה החדשה עובדת.

  1. העתיקו את השורה שלמעלה.
  2. היכנסו לניהול האחסון, לתיקייה assets, ופתחו את הקובץ admin.js.
  3. החליפו את השורה שמתחילה ב-var PASS_HASH בשורה שהעתקתם, ושמרו.
  4. חזרו לכאן והיכנסו עם הסיסמה החדשה.

    תמונות

    בוחרים תמונות מהמחשב או מהטלפון. הן מוקטנות אוטומטית לגודל שמתאים לאתר, והתמונה הראשונה היא זו שמופיעה בכרטיס. אפשר לגרור תמונות לתוך המסגרת.

      נתיבי התמונות (למתקדמים)

      איך מפרסמים את השינויים

      1. עורכים כאן את הדירות ומוסיפים תמונות. השינויים נשמרים בדפדפן הזה בלבד.
      2. לוחצים על הורדת העדכון לפרסום. יירד קובץ ZIP אחד שמכיל את data/listings.js ואת כל התמונות החדשות בתיקייה assets/img.
      3. פותחים את ה-ZIP ומעלים את התוכן שלו לאתר, לאותן תיקיות בדיוק: את listings.js לתיקייה data, ואת התמונות לתיקייה assets/img.
      4. מרעננים את האתר. הדירות המעודכנות מופיעות בעברית וברוסית.

      שינוי סיסמת הניהול

      הקלידו סיסמה חדשה, העתיקו את השורה שנוצרת, והחליפו בה את השורה var PASS_HASH = ... בראש הקובץ assets/admin.js. הסיסמה עצמה לא נשמרת בשום מקום, רק הטביעה שלה.

      חשוב לדעת: האתר בנוי כאתר סטטי, בלי שרת ובלי בסיס נתונים. לכן המסך הזה עורך עותק מקומי ומייצר את קובץ הדירות, והעלאת הקובץ היא הפעולה שמפרסמת בפועל. כך אין צורך בתשלום חודשי על מערכת ניהול, ואין סיכון שמישהו ישנה את האתר מרחוק.
