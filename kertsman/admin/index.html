ניהול הדירות

הזינו את סיסמת הניהול כדי להיכנס.

אחרי חמישה ניסיונות שגויים הכניסה ננעלת לזמן שהולך ומתארך. הסיסמה מגנה על המסך הזה מפני מבקרים מזדמנים, ואין להשתמש בסיסמה שמשמשת אתכם במקום אחר.

שחזור גישה

אין צורך לזכור את הסיסמה הישנה. בוחרים כאן סיסמה חדשה, מקבלים שורה אחת להחלפה בקובץ, ומאותו רגע הסיסמה החדשה עובדת.

ההוראות נשלחות לתיבת המייל של המשרד, זו שרשומה בשירות הטפסים.

  1. העתיקו את השורה שלמעלה.
  2. היכנסו לניהול האחסון, לתיקייה assets, ופתחו את הקובץ admin.js.
  3. החליפו את השורה שמתחילה ב-var PASS_HASH בשורה שהעתקתם, ושמרו.
  4. חזרו לכאן והיכנסו עם הסיסמה החדשה.

    תמונות

    בוחרים תמונות מהמחשב או מהטלפון. הן מוקטנות אוטומטית לגודל שמתאים לאתר, והתמונה הראשונה היא זו שמופיעה בכרטיס. אפשר לגרור תמונות לתוך המסגרת.

      נתיבי התמונות (למתקדמים)

      איך מפרסמים את השינויים

      1. עורכים כאן את הדירות ומוסיפים תמונות, ולוחצים על שמירת הדירה.
      2. כל שמירה עולה לאתר מעצמה, כולל התמונות. שורת המצב בראש המסך מראה מה קורה, ובסוף כתוב "נשמר ופורסם לאתר".
      3. אחרי כדקה מרעננים את האתר. הדירות המעודכנות מופיעות בעברית וברוסית, וכל דירה מקבלת עמוד משלה.
      4. אותו דבר קורה במחיקת דירה ובשינוי סדר הדירות. כפתור פרסום לאתר נועד לנסות שוב אם העלאה נכשלה, למשל כשהאינטרנט נופל באמצע.
      5. אם הפרסום לא עובד, למשל בלי אינטרנט, אפשר ללחוץ על הורדת העדכון, לקבל קובץ ZIP עם data/listings.js ועם התמונות, ולהעלות אותו לאתר ידנית.

      חיבור לאתר (פעם אחת)

      כדי שהמסך הזה יוכל לכתוב ישר לאתר, צריך להדביק כאן פעם אחת מפתח גישה שמוגבל לאתר הזה בלבד. יוצרים אותו ב-GitHub: בוחרים Only select repositories ואת המחסן של האתר, ותחת Repository permissions מגדירים Contents: Read and write. מעתיקים את המפתח, מדביקים כאן, ולוחצים על בדיקת החיבור.

      כבר שמור כאן מפתח. אפשר להחליף אותו: לוחצים על "ניקוי" ומדביקים מפתח חדש.

      המפתח נשמר בדפדפן שבו הדבקתם אותו, ולא נשלח לשום מקום חוץ מ-GitHub. כדאי להדביק אותו רק במחשב או בטלפון האישי, ולא במחשב משותף. אם מחשב אובד, נכנסים ל-GitHub ומבטלים את המפתח (Revoke) — ומאותו רגע הוא כבר לא יכול לשנות דבר.

      שינוי סיסמת הניהול

      הקלידו סיסמה חדשה, העתיקו את השורה שנוצרת, והחליפו בה את השורה var PASS_HASH = ... בראש הקובץ assets/admin.js. הסיסמה עצמה לא נשמרת בשום מקום, רק הטביעה שלה.

      חשוב לדעת: האתר בנוי כאתר סטטי, בלי שרת ובלי בסיס נתונים. המסך הזה מייצר את קובץ הדירות, ובפרסום כותב אותו ישר לאתר. כך אין תשלום חודשי על מערכת ניהול, האתר נשאר מהיר, ואף אחד לא יכול לשנות אותו בלי מפתח הגישה.
